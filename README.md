# МАОУ «Магнитогорская школа-интернат с углублённым изучением предметов для перспективных детей»

Официальный репозиторий данных и материалов для нового сайта школы.

---

## О школе

**Полное название:** Муниципальное автономное общеобразовательное учреждение «Магнитогорская школа-интернат с углублённым изучением предметов для перспективных детей»

**Краткое название:** МАОУ «Магнитогорская школа-интернат с углублённым изучением предметов для перспективных детей»

Школа-интернат для перспективных (одаренных) детей, реализующая модель **бесшовного инженерно-технического образования**.

### Миссия
Подготовка инженерных кадров для муниципалитета и региона, способных решать задачи устойчивого развития, цифровой трансформации и диверсификации экономики города и области.

### Основные направления
- Математика + Физика  
- Математика + Информатика  

Углублённое изучение: математика, физика, информатика.  
Дополнительные курсы инженерно-технической направленности:  
- Новая энергетика  
- Урбанистика  
- Искусственный интеллект  
- Беспилотные летательные аппараты

### Уровни обучения (бесшовное образование)
1. **Школа-интернат** — 7–9 классы  
2. **Проектная школа** ФГБОУ ВО «МГТУ им. Г.И. Носова» — 10–11 классы  
3. **Высшее образование** — МГТУ им. Г.И. Носова

### Особенности
- Обучение **бесплатное**
- Оплачиваются только проживание и питание (около 295 ₽ в день / ~7 000 ₽ в месяц)
- Проживание в комнатах по 3 человека
- Современные учебные лаборатории, Wi-Fi, спортивные объекты
- Закрепление мастеров-наставников с предприятий
- Социальные партнёры: ПАО «ММК», ММК-МЕТИЗ, «Ситно», «Росатом», МГТУ им. Г.И. Носова и др.
